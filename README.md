#  Criando um Dashboard Gerencial para Tomada de Decisões Com Power BI

Este repositório contém o projeto prático **"Criando um Dashboard Gerencial para Tomada de Decisões com Power BI"**, desenvolvido para a Formação **Power BI Analyst** na plataforma **Digital Innovation One (DIO)**.

---

##  Objetivo do Projeto

Reestruturar e otimizar um relatório financeiro corporativo focando na **Experiência do Usuário (UX/UI)**, aplicando:
- **Hierarquia Visual e Posicionamento**: Organização de KPIs e visuais de acordo com a prioridade analítica.
- **Contraste e Cores**: Tema escuro (*Dark Purple*) com destaques em azul/verde de alto contraste para facilitar a leitura.
- **Proporção e Alinhamento**: Estruturação uniforme de cartões, matrizes e gráficos.
- **Navegabilidade**: Botões de navegação interativos entre todas as páginas.

---

##  Páginas do Relatório

1. **Home**: Página inicial com introdução e botão de ação (*CTA*) para explorar o relatório.
2. **Sales Report**: Visão de vendas com cartões de KPIs, filtros de período e análise por produtos.
3. **Report de Lucro Detalhado**: Análise de lucratividade com Árvore de Decomposição (*Decomposition Tree*), gráfico de radar e gráfico de cascata (*Waterfall*).
4. **Report de Vendas Detalhado**: Análise temporal com gráfico de área (evolução mensal de vendas/lucro ordenada cronologicamente de Janeiro a Dezembro), matriz financeira e gráfico de colunas/linha.

##  Ferramentas Utilizadas

- **Power BI Desktop**: Modelagem Star Schema, visuais e regras de UX/UI.
- **DAX (Data Analysis Expressions)**: Métricas e agregações financeiras.
- **Power Query**: Limpeza e tratamento da base de dados *Financials*.
